How to Capture DNS Packets in Wireshark
  1. Open Wireshark on Windows and select your active network interface (e.g. Wi-Fi or Ethernet).
  2. Double click the interface to begin live packet capture.
  3. Generate DNS traffic by querying domains in this web tool, or run in PowerShell:
    nslookup google.com 8.8.8.8
  4. Type dns in Wireshark's top display filter bar to isolate DNS queries and responses.
  5. Stop capture (Ctrl + E) and save via File → Save As as .pcap.
Recommended Wireshark Display Filters Copy & Paste into Wireshark
dns All DNS
Filters all DNS traffic on UDP/TCP port 53.
dns.flags.response == 0 Queries Only
Shows only outgoing DNS query packets from clients.
dns.flags.response == 1 Responses Only
Shows only incoming DNS responses from nameservers.
dns.qry.type == 1 A Records
Filters queries for Host IPv4 Address (Type 1).
dns.flags.rcode != 0 Errors / NXDOMAIN
Isolates DNS response errors, NXDOMAIN, and SERVFAIL.
dns.qry.name contains "google" Domain Filter
Matches any query containing the specified domain name.

Cybersecurity Note: Encrypted DNS (DoH & DoT)
DNS-over-HTTPS (DoH, RFC 8484)

Encapsulates DNS queries inside standard HTTPS sessions over TCP port 443 using TLS encryption. Because traffic blends indistinguishably with web browsing, network firewalls and Wireshark cannot inspect query hostnames or response IPs without TLS session keys.

DNS-over-TLS (DoT, RFC 7858)

Wraps raw DNS datagrams directly within Transport Layer Security over a dedicated port (TCP 853). While port 853 signals that DNS is occurring, the query payload, transaction ID, and answers remain cryptographically opaque to eavesdroppers.
