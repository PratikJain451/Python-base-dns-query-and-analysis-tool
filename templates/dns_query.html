Understanding DNS Resource Record Types
A Record (Address)

Maps a domain name to a 32-bit IPv4 address (e.g., 142.250.190.46). Used by web browsers to locate host web servers over IPv4 networks.

AAAA Record (IPv6)

Maps a domain name to a 128-bit IPv6 address (e.g., 2607:f8b0:4005::200e). Provides the next-generation internet protocol routing address.

CNAME (Canonical Name)

Specifies that a domain is an alias for another domain name. When queried, the resolver follows the alias chain until it resolves the final canonical address.

MX Record (Mail Exchange)

Identifies mail servers responsible for handling email delivered to this domain. Each server is assigned a preference/priority integer, where lower values indicate higher priority.
