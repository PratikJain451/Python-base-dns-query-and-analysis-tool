Technical Interpretation & DNS Semantics
Resolution Latency

Latency represents the exact network round-trip time (RTT) measured using Python's time.perf_counter() between sending the UDP query to the nameserver and receiving the response packet.

NODATA vs. NXDOMAIN

NODATA / No Records indicates the domain exists and is active, but lacks that specific record type. In contrast, NXDOMAIN means the domain name is completely unregistered or absent from the DNS hierarchy.

MX Priority Mechanics

The MX priority integer dictates sending preference. Connecting mail transfer agents (MTAs) attempt delivery to the lowest numeric value first before failing over to backup mail relays.
