How dnspython Resolves This Query:
  1. A UDP socket is created and configured with a socket timeout (typically 3.0 seconds).
  2. A standard DNS Question Packet (QR=0, Opcode=0, RD=1) is formatted with the domain and QTYPE code.
  3. The packet is transmitted over port 53 to the specified nameserver ({{ record.resolver }}).
  4. Python's high-resolution timer time.perf_counter() measures elapsed milliseconds until the complete response packet arrives.
  5. The response records are decompressed and extracted into typed Python objects.
